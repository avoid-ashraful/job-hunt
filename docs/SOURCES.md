The scanner only reads public endpoints, identifies itself, and follows published access rules. A remote label alone does not establish Bangladesh eligibility; the existing location and company rules make that decision.

The [Himalayas API](https://himalayas.app/api) refreshes daily and warns that unauthenticated callers share a public allowance. A free key is optional if the daily request budget becomes unreliable.

Remote board probes used `curl` from this machine on 2026-10-17 with the scanner's identifying User-Agent. Counts above are raw feed inventory before age, role, location and dedup filtering; WWR counts are per feed. No region-feed challenge was bypassed. Remote OK's legal header is not a job. Captured job records live under `tests/fixtures/remote_boards/` and tests do not access the network or private data.

Run these feeds on the normal daily scanner schedule. Remote OK, Working Nomads and the default Jobicy configuration each make one feed request per run; WWR makes two. Jobicy must not be polled more than hourly; raising `max_pages` only follows cursors within the same traversal. Feeds are not a historical backfill: in particular, a `days` window over seven days cannot recover older Jobicy posts. Required board attribution remains visible in the report's application links, with original source URLs also retained in `ats_metadata.source_url`.
